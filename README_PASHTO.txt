HAKIMI CARS - د نصب او چلولو لارښود

اړین شیان:
1) په Windows کمپیوټر کې Python 3.10 یا نوی نصب کړئ.
2) د پروژې فولډر خلاص کړئ.
3) د فولډر په پته کې CMD خلاص کړئ.
4) دا امرونه په ترتیب اجرا کړئ:

   py -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   py app.py

5) په براوزر کې دا پته خلاصه کړئ:
   http://127.0.0.1:5000

د اډمین پاڼه:
   http://127.0.0.1:5000/admin/login

لومړنی اډمین حساب:
   Username: admin
   Password: Hakimi@2026

- د عام استعمال/انټرنېټ ته د خپرولو لپاره SECRET_KEY د چاپېریال متغیر په توګه وټاکئ، HTTPS فعال کړئ، او د اډمین پاسورډ بدل کړئ.

- د ډیمو موټرونو عکسونه د ځای ناستي په بڼه ښودل کېږي؛ اډمین کولای شي خپل عکسونه پورته کړي.
